## 3. 三条 FAIL 的根因（同一原因的两个面）

### 3.1 D34 / D35（换表后的暗窗与恢复）

我用错了观测量：**BLANK 由 TCON 决定，不由 Data 的 `col_valid` 决定**。
换表在槽 1027 的 LATCH 上升沿使 `col_valid=0` 后，TCON 仍照常释放 BLANK，因此**不存在"没有显示窗"的槽**，而是出现"窗存在、768 路全关"的一窗。`no_win_slots` 因此恒为 0，D34 的 `1 个无窗槽` 判据必然失败；D35 里的 `disp_windows` 增量也因此是 3 而不是 2。

### 3.2 同一窗的 1524 字节失配（连带 D35、D56）

逐列账本（`t5_column_ledger.csv`）直接给出证据：

```
slot,exp_col,exp_frame,scan_col,tag0,frame0,tag1,frame1,bad_bytes,lut_tab
1027,1,1,1,1,1,1,1,0,0
1028,2,1,2,2,1,2,1,1524,1     <-- 唯一失配窗
1029,3,1,3,3,1,3,1,0,1
1030,4,1,4,4,1,4,1,0,1
```

槽 1028 显示的是**绝对列 1026**（`1028-2`），它的装载窗在槽 1026 的 `[832,1600)`，**在换表（槽 1027 的 828 沿）之前**完成 —— 所以它的 `map_disp` 就是**表 A** 的映射，RTL 行为正确；是我把期望表提前了一窗（`cur_tab` 在换表沿就置 1，而没有按"该列装载时刻"归属）。

失配数 1524 也自洽：每窗检查 768 通道 × 3 项（raw/map/PAM）＝2304 项，raw 全对（768），map+PAM 应错 1536 项，其中 raw=0x00 与 0xFF 的 12 个通道在 A/B 两表下映射相同 → **1536−12 = 1524**，与实测完全一致。

同一窗的 16 个 PWM 采样通道也全部失配（`pwm_bad=16`），因为该窗 768 路确实全关（`col_valid=0`），而我的期望按表 B 算出了非零宽度。

### 3.3 正确语义（下一轮只需改 TB 三处，RTL 不动）

1. 期望表按**列的装载时刻**归属：显示槽 S 的列 `S-2` 用表 B 当且仅当 `(S-2) >= 换表槽`；
2. "换表后熄屏"改为判 **该窗 768 路 `ch_en` 全 0 且 `col_valid=0`**（窗仍存在、BLANK 仍低），不是"无窗"；
3. 该窗的 PWM 期望应为 0 而非按新表算，并且这一窗要从 `blank_novalid` 的"异常"里显式豁免（它是**合同要求**的熄屏，不是违约）。
