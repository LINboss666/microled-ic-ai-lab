# T2A 接口契约（实现前冻结）

**任务** `TCON-T2A-20261114` ｜ 依据 V1.3 原件（SHA-256 `6b61e4ab…54afaa`）§8/§9/§12/§14 ｜ 1 页

## 1. 时钟与范围

| 项 | 约定 |
|---|---|
| `CLK_REF` | 100 MHz，10 ns/周期，唯一时基 |
| `PCLK` | **课程模型强制与 `CLK_REF` 同源同相**（`PCLK = CLK_REF`）。**不声称已验证 CDC**；异步输入（`fault_n`/`cfg_*`）只做同步假设并披露局限 |
| 缓存 | **仅两个 768 B 列缓存**（共 1536 B）。无帧缓存、无帧转置——整帧转置在外部 DSP（V1.3 §3/§9） |
| 灰阶引擎 | 归属 **Data Driver**，不在 TCON。TCON 只产生公共时序与像素字节流 |
| 本轮不做 | 384/512 路晶体管级阵列、SPI 寄存器、中断、电平搬移、STA、PVT/SOA |

## 2. 列流水（一列 976/977 周期）

| 周期（槽内） | 事件 |
|---|---|
| `[0, 768)` | **接收列 N**：768 B，1 B/周期；同时显示列 N−2 的 PWM 窗口 |
| `768` | `BLANK` 上升 |
| `[828, 832)` | `LATCH` 脉冲 40 ns——把列 N−1 的装载结果原子切换 |
| `831`（下降沿） | **首字节预取**：D0/D1 输出列 N 的第 0 字节 |
| `[832, 1600)` | **`load_active` 装载列 N**：768 周期 = 7.68 µs，跨槽至下一槽 624（前一槽为长槽则 623） |
| `[840, 844)` | `PWM_START` 40 ns |
| `[880, 884)` | `SCAN_STB` 40 ns，锁存 `COL_ID` |

**bank 选择**：列 N 用 bank `N mod 2`。接收列 N+1 写 bank `(N+1) mod 2`，与列 N 的读取并行，故 2 bank 足够。
**禁令**：不得覆盖仍在装载的列。列 N 的读取止于 1600，列 N+2 的写入始于 1952，间隔 352 周期。

## 3. DCLK 与 D0/D1 采样相位

DCLK 在装载窗内由 `load_run` 派生（`dclk = load_run && !load_cnt[0]`），**首个上升沿固定在周期 832**：

| 量 | 值 |
|---|---|
| DCLK 周期 / 频率 | 20 ns / **50 MHz**（100 MHz ÷ 2），窗内占空比 50 % |
| 窗内上升沿 | 832, 834, …, 1598 → **384 个** |
| 第 k 字节加载沿 | 周期 `831 + 2k` 的**下降沿**（`CLK_REF` 反相沿） |
| 第 k 字节采样沿 | 周期 `832 + 2k` 的**上升沿**（DCLK 上升） |
| 建立时间 | 5 ns（≥ V1.3 目标 3 ns） |
| 保持时间 | 5 ns（≥ V1.3 目标 1 ns） |

**奇偶映射（本契约定义，必须照此实现）**：第 k 个 DCLK 采样沿上
- `D0` = bank 中**偶数字节** `2k` → 对应**行 2k**（第 0,2,…,766 行）
- `D1` = bank 中**奇数字节** `2k+1` → 对应**行 2k+1**（第 1,3,…,767 行）

即 D0 驱动偶数行、D1 驱动奇数行，各 384 行。改映射只需换 bank 的读写地址，不改时序。
**DCLK 只在装载窗内翻转**（窗外保持低）。这是相对"自由运行 DCLK"的**已知偏离**，目的是让首采样沿确定可测；真实芯片可连续供钟。

## 4. `rx_ready` 的真实语义（回应 T1R 复审 F4）

| 信号 | 语义 |
|---|---|
| `rx_ready` | **模式级**"视频前端已就绪"，不是"当前列已收满"。它参与 `safe`，允许整体冻结（T1 已验收的行为） |
| `bank_valid[1:0]` | **列级**有效标志：某列恰好收满 768 B 且见到 `COL_SYNC` 才置位 |
| 当前列未收满 | **不**反映到 `rx_ready`，因此不会冻结整机、不会打断上一列的有效装载 |
| 装载时 bank 无效 | 该列 384 个字节全部输出 `8'h00`（Data 锁存到 0 = 该列不发光），**帧时序不受影响**；置 `err_flags` |
| 截止 | 架构截止是 `831`（装载启动前 bank 必须有效）。超过则 `err_flags[3]`，该列作废 |
| `fault_n` 拉低 | 优先：`BLANK` 当拍拉高、`load_active` **0 周期**关闭、计数清零；欠载/溢出的列作废 |

## 5. 字节错误分类

| 条件 | 标志 | bank |
|---|---|---|
| `COL_SYNC` 到达时字节数 < 768 | `err_flags[0]` underrun | 作废 |
| 第 769 字节（`de` 且 idx==768） | `err_flags[1]` overflow | 作废（sync 时 idx≠768） |
| 同列第二个 `COL_SYNC` | `err_flags[2]` dup | 保留（首列数据仍有效） |
| 到 831 仍无 `COL_SYNC` | `err_flags[3]` missing | 作废 |
| `VSYNC` 不在 `COL_ID==0` | `err_flags[4]` vsync phase | 不影响数据 |

**停顿策略**：`DE` 在截止（831）前收齐 768 B 即通过（余量 63 周期，从 768 算起）；
超截止则按 §4 作废。**不得**把 Data 装载的 200 周期净余量当成视频接收的余量（两者差 140 周期）。
