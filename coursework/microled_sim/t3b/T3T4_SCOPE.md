## 1. 五颗芯片谁产生什么

```
视频前端 ──VIDEO_D[7:0], PCLK, DE, COL_SYNC, VSYNC──▶ TCON
                                                      │
   TCON ──D0[7:0] + DCLK + LATCH + PWM_START + PWM_TICK──▶ Data#0（偶数行 0,2..766）
   TCON ──D1[7:0] + 同上 ─────────────────────────────▶ Data#1（奇数行 1,3..767）
   TCON ──COL_ID[9:0] + SCAN_STB──▶ Scan#0（COL_ID[0]=0，本地 512 路）
   TCON ──COL_ID[9:0] + SCAN_STB──▶ Scan#1（COL_ID[0]=1，本地 512 路）
   TCON ──BLANK──▶ 全部 4 颗
   Data/Scan ──FAULT_n（开漏线与）──▶ TCON
```

一个槽内四列同时活着（T2B 已冻结）：`rx = s`、`fwd = s`、`disp = s−1`、`lit = s−2`。
Data 的显示 bank 是 `s−1`，Scan 在槽 s 末尾锁存、在槽 s+1 的窗口点亮 `s−1`。

## 5. 时钟域与相位

| 域 | 频率 | 本轮假设 | 状态 |
|---|---|---|---|
| `CLK_REF` | 100 MHz ±100 ppm | TCON 内部主时基 | 已验证（T1） |
| `PCLK` | ≤100 MHz | 与 CLK_REF 同源或需验证 CDC | `OPEN`（CDC 未验证） |
| `DCLK` | 50 MHz 连续 | Data 侧唯一采样沿；LATCH/BLANK 在 DCLK 上被采样 | 相位模型已验证（针脚级监视器） |
| `PWM_TICK` | 8.333 MHz（Hybrid 120 ns） | 在 DCLK 域内被计数；**跨域毛刺未验证** | `OPEN` |
| `SCAN_STB` | 102.4 kHz | Scan 侧上升沿锁存 | 针脚级已验证 |

**明确不声称**：没有做 CDC 签核、没有做毛刺/亚稳态分析。
`BLANK` 按规格做成**组合优先关断**（异步），因此它本身带来一个潜在的异步路径——
这一点登记为 `OPEN_ASYNC_BLANK`，需要综合/时序阶段处理，不在本轮数字验证范围。

## 6. 可综合边界

| 类别 | 内容 |
|---|---|
| **本轮新建可综合 RTL** | `data_driver`（384 路装载/双 bank/LUT/灰阶引擎/门控） |
| **保持为仿真 oracle** | `data_model`（Data 独立验收参照）、`scan_model`（Scan 参照）、`data_pin_mon`/`scan_pin_mon`（针脚级测量） |
| **TCON 既有 RTL** | 不改（`tcon_*` 6 个文件） |
| **明确属于模拟/电气、不在数字范围** | 8 档 PAM 电流源、恒流下拉、`I_PAM0…7` 档值与修调、Scan 高侧 512 路驱动管与 8.68 Ω 上限、阵列 RC、光学标定、版图 DRC/LVS/PEX、流片 |
| **未实现的上层** | SPI 寄存器堆（本轮只用端口注入配置）、中断、`TEST_EN/TEST_CLK` 夹具通路、UVLO/OTP 传感器 |

`PAM_CFG=01`（4 档）与 Pure 8-bit PWM 的 TCON 侧 30 ns tick 都列为 `OPEN`，
见 `GRAY_CODE_MAPPING.md` §4。

## 7. A 段冻结的结论

1. 灰阶映射**有明确规定**（256×9 LUT + 双银行 + COMMIT 互锁），不是 OPEN，可以进入编码。
2. LUT 的 256 项内容按段0236 算法可**完整复现**（268 / 256 / 1-of-512 / 21.78 % 四项全对），
   标 `DERIVED_REPRODUCES_V13`；RTL 不内置该表，由 TB 作为标定镜像灌入。
3. 只有一个 `OPEN` 会挡住"系统级 Hybrid 全功能"的说法：Pure 模式的 30 ns tick 发生器未实现；
   它不挡 T3 单模块验证（单元级可用不同 `MAX` 参数验证计数语义）。
4. 因此**进入 B 段（T3 编码）**，不触发任务书 §A 的停止条件。
