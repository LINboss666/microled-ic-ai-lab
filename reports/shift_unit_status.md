## 端序问题已彻底定死（已验证）

` spectre -h bsim4 ` 的权威 Synopsis 是：

```
Name ( d g s b ) ModelName     <- 漏 栅 源 衬，衬极在最后一位
```

（`-h nmos` 会报 `no such component`，因为 Spectre 里组件名就是模型类型 `bsim4`。）

用两个只用字面量、无 subckt/无 parameters 的最小题测验证（`spectre/tg_test_on.scs`、`tg_test_off.scs`）：

```
TG_ON : out@Vd=1.8 = 1.798740e+00  relerr=7.00e-04   PASS
TG_ON0: out@Vd=0   delta=1.792e-10                    PASS
TG_OFF: out@Vd=1.8 delta=1.041e-03（开关关断，靠 1MΩ 保持 0）PASS
```

→ 传输门写法 `(A 栅 B 衬)` 正确可用；我之前两种写法分别把数据变成栅极、把时钟节点变成源极，这正是前几次"全节点分压到 1.1 V / 输出 1.52 V = VDD−Vth"的成因。

## ~~还剩的真问题（不是工具问题，是单元结构选择）~~ —— 本节作废，见开头更正

修正端序后，链子暴露出**保持/写入的强度冲突**：同尺寸节点锁存链里

- TG 强于本管 keeper（run a：TG 2µm/4µm vs keeper 1µm/2µm）→ 能写入，但后一级会在前一级该保持的相位把它的值拽走：实测 `q1` 在 `clk=1` 期间从 1.8 V 塌到 ~0，`q2` 在自己窗口内 max 仅 6 mV。
- keeper 强于 TG（run b：TG 1µm/2µm vs keeper 2µm/4µm）→ 写不进去，三级同时跟随 `d0` 且高电平退化到 1.52 V。

结论：**纯互补两相时钟 + 同尺寸反相器锁存链，无法同时满足可写与可保持。** 真实扫描/行驱动单元用 pulse-D（C²MOS）单相结构，或引入真正的时钟非交叠 + 分相尺寸设计。所以下一步不是继续调宽长，而是**换单元拓扑**：

1. 改用 pulse-D 单时钟结构（少管、无交叉导通冲突，是 gate/scan driver 的常见做法）；
2. 或保留两相但生成带死区的非交叠时钟，并把 keeper 与 TG 按"写入 > 本管保持、且 < 前级保持"分档设定；
3. 同时给链加异步复位（真实扫描驱动器都有 RST/BLANK），使初态与换列安全由设计保证而不是靠上电巧合。
