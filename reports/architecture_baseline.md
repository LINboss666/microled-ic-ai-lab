> **Topology correction (2026-10-04)**: the first version of this file assumed data = columns and scan = rows. The course specification says the opposite: **scan drivers are the COLUMN drivers (512 x 2), data drivers are the ROW drivers (384 x 2)**. Consequently a selected scan electrode carries 768 pixels, so I_SCAN_MAX = 768 x 15 uA = **11.52 mA**, not 15.36 mA.
