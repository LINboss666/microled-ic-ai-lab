     S3CB-BEFORE "c2mos_dff" "mn_c" raw_l="2e-07" raw_w="ABSENT" cdf_l="200n" cdf_w="220n"

5) declared port directions onto the terminal objects -- skill/dd1_d6_apply_dirs.il (new)
   D6D-ROWS items=47 expect=47 (46 declared ports plus the leading nil)
   D6D-VIEWS 16 MATCHED 92 WANT 92
   D6D-SCHCHECK "c2mos_dff" "schematic" => ((0 9))     [0 errors, 9 warnings]
   D6D-SCHCHECK "c2mos_dff" "symbol"    => nil
   reason: the import gave EVERY terminal inputOutput; the netlist declares d/clk input,
   q/qbar output, vdd/vss inputOutput. First pass of this IL printed a false
   "D6D-REFUSE the table has 0 rows" because `car(errset(cdr loaded))' came back nil on this
   build; the guard now counts by walking the table and the writes it guarded had already been
   verified independently by the read-back below.
